2026 最新 Clash Verge Rev 零基础保姆级配置与节点导入指南

Clash Verge Rev 是目前公认最现代、最稳定且兼容性最广的 Clash 跨平台客户端。本文将通过图文步骤，带您 3 分钟内完成安装、汉化、订阅导入与顺畅联网。

一、准备工作：下载正版客户端

在开始之前，请务必从官方原版渠道下载，严禁从任何未经核实的第三方下载站下载被二次修改的安装程序，以防个人数据泄漏。

  • Windows 用户：请前往 【客户端下载页面】 下载 Clash.Verge_x64-setup.exe 安装程序；
  • macOS 用户：M 系列芯片选择 aarch64.dmg，Intel 芯片选择 x64.dmg；
  • 官方 GitHub 仓库：clash-verge-rev/releases ↗

二、第一步：安装与切换中文界面

双击下载的安装文件，按照提示点击“下一步”完成安装后启动软件。如果初始界面显示为英文，请按以下步骤切换：

  1. 点击左侧导航栏底部的 Settings (设置) 图标；
  2. 在 Verge Setting 中找到 Language (语言) 选项；
  3. 在下拉框中选择 简体中文 (zh-CN)，软件界面将立即自动更新为中文。

导入步骤：

  1. 在 Clash Verge Rev 左侧菜单点击 【订阅】 (Profiles)；
  2. 在顶部的输入框中，粘贴上方复制好的订阅链接；
  3. 点击右侧的 【导入】 (Import) 按钮；
  4. 等待 2-5 秒，列表中会出现名为 jiedianku.online - 免费节点库 的订阅卡片；
  5. 重要：鼠标左键单击该卡片选中它（选中的卡片边缘会高亮变为蓝色）。

四、第三步：测速与选择节点

导入订阅后，点击左侧菜单的 【代理】 (Proxies) 页面：

  • 在右上方点击 【延迟测速】 (闪电图标 ⚡)，软件会自动测试所有节点的网络延迟；
  • 建议在 【节点选择】 (Proxy) 组中，选择绿色延迟（如 30ms ~ 60ms）的 香港 或 日本 节点；
  • 模式推荐选择 【规则】 (Rule) 模式：国内网站直连不消耗代理流量，国外网站自动走代理，智能极速。

五、第四步：开启系统代理与畅游网络

回到软件左侧菜单的 【设置】 (Settings)：

  • 找到 【系统代理】 (System Proxy) 开关，将其点击开启（开关变为蓝色激活状态）；
  • 此时打开浏览器，访问海外学术或视频网站（例如 YouTube 或 Google），即可顺畅打开！
  • 如果遇到某些特定应用不走代理，可以在设置中开启 【TUN 模式】（需授予管理员权限）。
⚠️ 常见问题排查 Checklist：
  • 测速全部 Timeout 超时：检查电脑系统时间是否准确，请在 Windows 设置中同步一下北京时间；
  • 网页打不开但显示已连上：检查是否有其他杀毒软件或网络防火墙阻止了 Clash 内核运行；
  • 无法访问海外 AI (ChatGPT)：进入代理列表切换到 美国 或 原生 IP 节点，并清理浏览器缓存。
