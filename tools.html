最常用

出口 IP 与归属地检测 (IPinfo)

全球权威 IP 数据库。一键查看当前设备公网 IP、地理位置（国家、城市、经纬度）、ISP 运营商与 ASN 广播编号。连上节点后访问该工具，若显示为海外即代表代理生效。

打开 IPinfo 检测 ↗ 备用 IP.SB ↗
🛡️
安全核心

DNS 泄漏测试 (ipleak.net)

检测你的域名解析请求是否直接发送给了国内运营商（中国电信/移动/联通）。如果测试结果中出现国内 DNS 地址，说明存在 DNS 泄漏，应在客户端开启 Fake-IP 模式。

前往 IPLeak 检测 ↗ DNSLeakTest ↗
🌐

WebRTC 隐私漏洞探测

部分网站（如 Google, Discord）会通过 WebRTC 协议直接探测你的真实内网及本地公网 IP，绕过普通 HTTP/Socks5 代理。在此工具中可检测是否已被抓取。

打开 BrowserLeaks 测试 ↗ 防漏教程
🎬

流媒体与 AI 模型解锁检测

检验节点是否能观看 Netflix 非自制剧、Disney+、HBO Max，以及是否通过 OpenAI / ChatGPT 严格的风控黑名单。可使用专用检测脚本或在线测试页面。

全球宽带测速 (Fast.com)

由 Netflix 官方提供的极简测速服务，直接从全球最近的 CDN 服务器加载数据，真实反映节点在高峰期的视频吞吐能力与丢包率。

🩺 节点连接故障快速排查三部曲

1. 本地连接测试

打开命令提示符 (CMD)，输入 ping 223.5.5.5，确认自身宽带正常连通互联网。

2. 客户端延迟测试

在 Clash 或 v2rayN 客户端内点击闪电测速，若全红请前往 【节点库】 重新更新订阅。

3. 代理与IP验证

开启系统代理后点击上方 IPinfo，确认出口 IP 变为海外地址。
